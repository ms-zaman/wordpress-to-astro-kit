<p>This is a <strong>custom post type</strong> entry. It exists to prove that a WordPress type the kit did not know about can travel the whole pipeline: content directory, collection, identity, permalink, resolver, route, dist, browser.</p>
<p>Nothing about it is specific to any real site. The type is called <code>product</code> because that is the most ordinary custom type a WordPress install has, and its URL prefix is configuration.</p>
